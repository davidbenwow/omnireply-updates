Setup steps

Follow these steps once on each Thunderbird installation.

1

Download OmniReply

Click Download OmniReply above. The stable link always points to the newest available XPI after updates are published.

2

Find your V4 API key

Open v4.vdm-vsg.de, go to Account, and look just below your signatures. Copy the API key.

3

Allow the internal XPI in Thunderbird

  • Open Thunderbird → Settings.
  • Go to General, scroll all the way down, and click Config Editor.
  • Search for xpinstall.signatures.required.
  • Make sure it is set to false. If it is true, double-click it to change it to false.
4

Install the XPI file

  • In Thunderbird, open Tools → Add-ons and Themes.
  • Click the settings gear.
  • Choose Install Add-on From File....
  • Select the XPI file you downloaded.
5

Activate OmniReply

Open the OmniReply extension settings, paste your V4 API key, and click Test connection.

6

Add your Cover Playground links

Paste your personal Cover Playground link for each recognized imprint account. These links let OmniReply include your own submission link in generated replies.

7

Optional: adjust voice settings

You can edit the default voice settings manually. Learning from your sent folder is optional.
